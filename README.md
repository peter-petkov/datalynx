# Datalynx

A drop-in enhancement for an `<input>` with a `<datalist>`: a searchable suggestions popover in the look of [Platypicker](https://github.com/peter-petkov/platypicker), with the same search, long lists, languages, skins and phone sheet, while the `<input>` stays the real control. In browsers without support, the native datalist works as before.

Work in progress: nothing to install yet.
