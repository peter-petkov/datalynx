Datalynx work in progress

Datalynx

A searchable suggestions popover for an <input> with a <datalist>, sibling of Platypicker. The input stays the real control: type freely, or pick a suggestion.

Labels and subtexts

An option's label is its row's text and data-subtext sits beside it; picking it puts its value in the input. Search matches the label, the subtext and the value: "ams", "nl" and "amsterdam" all find Amsterdam, and initials work too ("nyc").

Long lists

Rows are shown a batch at a time, more as the list scrolls, so a datalist of thousands opens at once.
